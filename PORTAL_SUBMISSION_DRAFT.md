# Intelligent Contracts submission draft (English, under 1,000 characters)

ConsensusGuard is a reusable GenLayer evidence-bound decision primitive. A requester commits a claim, immutable criteria, HTTPS evidence URLs, and the expected SHA-256 digest of each source response before evaluation. The leader and validators independently fetch and hash every source, then independently classify each hash-verified source as SUPPORTS, REFUTES, or UNCLEAR. Consensus requires an exact match on ordered source observations and labels; a shape-only or leader-trusting validator cannot pass. Deterministic integer thresholds produce VERIFIED, REJECTED, or an agreed INCONCLUSIVE result, while protocol-level validator disagreement writes no decision. Decisions are append-only, replay-protected, and support one requester-authorized appeal with a new evidence manifest. Hashes bind bytes but do not prove source authenticity or truth. Tests and any deployment evidence will be linked only after they are actually run.

The threshold counts hash-verified URL entries on distinct normalized hostnames. Distinct hostnames, including sibling subdomains, do not prove distinct ownership or independent publishers; the contract does not implement a publisher registry or signed publisher attestations. `policy_sha256` uses the versioned `ConsensusGuard.Policy.v1` canonical JSON encoding with separate claim and criteria fields. This is a draft only and has not been submitted.
